# 每行一条更新说明。发布新版本前请修改本文件。
# v0.3.9

- 清洗完整性改为按CSV首列逐行核对证据ID，集中抄写ID或缺少数据行不再被判定为清洗完成。
- 本次升级会重新清洗一次已缓存资料，因为旧版清洗结果的完整性无法可靠保证；这是正常升级行为，不是重复故障。
- 授权服务器短时不可连接时保留最近一次成功验证，72小时宽限期内不中断正在生成的报告。
- 授权刷新增加主进程互斥和60秒节流，模型任务完成后只读取轻量积分钱包，不再反复写授权文件。
- 积分窗口显示服务器真实余额和最近流水，报告完成后显示本次消耗和剩余积分。
- 表格无法逐行识别时明确提示降级原因；项目资料块缺失时其余项目内容仍可恢复并提示重新上传。
- Token日志自动轮转，来源告警可跨重启保留；清洗保存、表格解析、分析分组和报告缓存完成性能优化。
- GitHub Actions 正式运行核心回归、更新流程与HTML视觉测试后才允许打包发布。

# v0.3.7

- 修复同一台电脑重启后设备码变化的问题，兼容历史设备码并持久保存稳定设备标识。
- 旧授权升级时自动完成设备凭证刷新，不再向普通用户显示技术参数提示。
- 本机安全存储仍保留原激活码时，可一键重新验证，无需再次寻找或手动输入。
- 激活请求增加主进程防重复提交，避免快速点击造成重复绑定或重复请求。
- 增加安全诊断信息复制，只包含软件版本、设备码前缀和授权状态，不包含激活码或设备凭证。
- 后台解绑、凭证失效和本地保存异常时提供明确恢复入口；历史报告仍可查看和导出。
- 生成 Windows x64、macOS Apple Silicon 和 macOS Intel 三个平台安装包，并同步正式更新服务器。

# v0.3.6

- 服务器后台解除绑定后，软件会自动返回激活码输入页，不再保留已失效的设备会话。
- 软件重新获得焦点、从后台恢复及定时检查时都会同步服务器授权状态。
- 输入新激活码成功后清除上一张授权遗留的自动保存误报。
- 未激活或等待重新激活期间暂停自动保存，历史资料和报告文件不受影响。
- 生成 Windows x64、macOS Apple Silicon 和 macOS Intel 三个平台安装包。
- 本次仅发布 GitHub 安装包，不同步到自有更新服务器。

- 更新内置 AI 服务授权配置，保持 CCG 模型地址和 `gpt-5.5` 模型不变。
- 重新生成 Windows x64、macOS Apple Silicon 和 macOS Intel 三个平台安装包。

# v0.3.3

- 更换电脑改为当前设备安全解绑，新电脑直接输入原激活码重新绑定，不再使用换机码。
- 设备解绑改用 `/api/license/device/unbind`，启动校验改用 `/api/license/device/status`。
- 设备会话和设备凭证在本机加密保存；解绑成功后立即清除旧设备授权和本地积分显示。
- 服务器保留真实剩余积分，新电脑绑定时按服务器余额恢复，不重新发放激活码初始积分。
- 旧版本地授权无需重新输入激活码，可直接清除本机授权；已有服务器授权则使用设备凭证直接解绑。
- 兼容 v0.3.2 服务器授权：缺少设备凭证时由软件在原电脑自动刷新，再执行解绑。
- 新激活统一以服务器为准，客户端不再离线接受内置激活码；旧哈希表只用于识别已经激活的本机旧记录。
- 服务状态显示当前主激活码，默认隐藏并支持显示、复制；主激活码仅加密保存在当前电脑。
- 积分码只给当前钱包增加积分，不覆盖主激活码或设备绑定；重复输入同一积分码不会重复入账。
- 解绑失败、冷却期、次数限制或机器码不匹配时保留本机授权，并显示服务器返回的原因。

# v0.3.2

- 高可信、无长文案且整理后不超过 12,000 字的结构化表格改为本机清洗，不调用模型、不扣积分。
- 8 个分析步骤改为固定上游依赖，减少重复携带无关中间结果。
- 使用版本化精简运行规则替代每步重复发送完整 Skill，同时保留全部报告硬约束。
- 完全相同的资料和要求在 30 天内可直接复用完整报告，扣除 0 积分；也可选择重新生成。
- 设置页增加完整报告缓存统计与清理。
- 普通用户界面只显示剩余积分，不显示开发统计入口。
- 服务状态页改为按需读取缓存，避免点击后卡顿或白屏。
- 报告生成按实际使用情况自动扣除积分。
- 保留旧版已激活授权；后台新生成的 ProductOperationReport 积分码可继续充值，同一码只入账一次，其他软件的码不能入账。
- 内置旧激活码不再是永久模型授权，首次升级或输入后一次性发放 2000 积分；同一个旧码不会重复发放。
- 发布 Windows x64、macOS Apple Silicon 和 macOS Intel 三个平台安装包。
- 本次不部署激活服务器或更新服务器；更换电脑功能需服务器端接口启用后才可供正式用户使用。

本版本生成三平台安装包，但暂不发布到自有更新服务器。
新增积分余额、充值码入账和防止重复入账保护。
