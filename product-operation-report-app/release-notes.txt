- 重新生成 Windows x64、macOS Apple Silicon 和 macOS Intel 三个平台安装包。

# v0.3.3

- 更换电脑改为当前设备安全解绑，新电脑直接输入原激活码重新绑定，不再使用换机码。
- 设备解绑改用 `/api/license/device/unbind`，启动校验改用 `/api/license/device/status`。
- 设备会话和设备凭证在本机加密保存；解绑成功后立即清除旧设备授权和本地积分显示。
- 服务器保留真实剩余积分，新电脑绑定时按服务器余额恢复，不重新发放激活码初始积分。
- 旧版本地授权无需重新输入激活码，可直接清除本机授权；已有服务器授权则使用设备凭证直接解绑。
- 兼容 v0.3.2 服务器授权：缺少设备凭证时由软件在原电脑自动刷新，再执行解绑。
- 新激活统一以服务器为准，客户端不再离线接受内置激活码；旧哈希表只用于识别已经激活的本机旧记录。
- 服务状态显示当前主激活码，默认隐藏并支持显示、复制；主激活码仅加密保存在当前电脑。
- 积分码只给当前钱包增加积分，不覆盖主激活码或设备绑定；重复输入同一积分码不会重复入账。
- 解绑失败、冷却期、次数限制或机器码不匹配时保留本机授权，并显示服务器返回的原因。

# v0.3.2

- 高可信、无长文案且整理后不超过 12,000 字的结构化表格改为本机清洗，不调用模型、不扣积分。
- 8 个分析步骤改为固定上游依赖，减少重复携带无关中间结果。
- 使用版本化精简运行规则替代每步重复发送完整 Skill，同时保留全部报告硬约束。
- 完全相同的资料和要求在 30 天内可直接复用完整报告，扣除 0 积分；也可选择重新生成。
- 设置页增加完整报告缓存统计与清理。
- 普通用户界面只显示剩余积分，不显示开发统计入口。
- 服务状态页改为按需读取缓存，避免点击后卡顿或白屏。
- 报告生成按实际使用情况自动扣除积分。
- 保留旧版已激活授权；后台新生成的 ProductOperationReport 积分码可继续充值，同一码只入账一次，其他软件的码不能入账。
- 内置旧激活码不再是永久模型授权，首次升级或输入后一次性发放 2000 积分；同一个旧码不会重复发放。
- 发布 Windows x64、macOS Apple Silicon 和 macOS Intel 三个平台安装包。
- 本次不部署激活服务器或更新服务器；更换电脑功能需服务器端接口启用后才可供正式用户使用。

本版本生成三平台安装包，但暂不发布到自有更新服务器。
新增积分余额、充值码入账和防止重复入账保护。
